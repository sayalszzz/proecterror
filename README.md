# Ресторан proecterror

Рабочая учебная версия приложения группы 6 с намеренно оставленными ошибками рефакторинга и оптимизации. Интерфейс позволяет добавлять блюда, искать и фильтровать меню, формировать заказ, просматривать историю и менять статус.

Полный перечень проблем находится в `ERRORS.md`.

## Запуск

1. Открыть проект в IntelliJ IDEA.
2. Обновить Maven-зависимости.
3. Запустить `src/Main.java`.

SQLite-файл создаётся автоматически и не очищается при повторном запуске.
